Les variables peuvent contenir des **nombres**, et Python sait compter :
`+` `-` `*` `/`.

Avec les deux variables ci-contre, affiche :

1. leur **somme** (première ligne)
2. leur **produit** (deuxième ligne)

```
19
84
```

Sans écrire `19` ni `84` toi-même, évidemment — c'est Python qui calcule.
