Jusqu'ici tes programmes parlaient. Ils savent aussi **écouter** : `input()`
attend que quelqu'un tape quelque chose, et te le donne.

```python
reponse = input()
```

Lis un prénom, puis affiche `Bonjour <prénom> !`.

Par exemple, si on tape `Madeline`, ton programme affiche :

```
Bonjour Madeline !
```

Ton code doit marcher **quel que soit** le prénom tapé — chaque test essaiera
le sien.
