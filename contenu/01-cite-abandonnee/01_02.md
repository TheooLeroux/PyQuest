Pour glisser des variables **dans** un texte, Python a les *f-strings* :

```python
nom = "Théo"
print(f"Photo de {nom} !")   # → Photo de Théo !
```

Les deux variables ci-contre sont déjà remplies. Utilise-les pour afficher
exactement :

```
Madeline est à 800 m.
```
